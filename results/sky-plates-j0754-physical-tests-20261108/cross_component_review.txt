FAST EW covariance
The EW gradient is correct for the implemented WLS-continuum estimator. The fitted coefficients are a linear map beta=B*y using diagonal continuum weights. Though this is WLS rather than full-covariance GLS, propagating the complete smoothed covariance via gradient*C*gradient and B*C*B^T is valid for that chosen estimator. The direct line gradient and continuum influence gradient are both present; the explicit1+continuum_bias factor in the latter is necessary and correct. Their cross term retains line/continuum covariance from smoothing. No independence assumption is silently imposed on the convolved output pixels.
The Gaussian degradation is a linear operator with added width sqrt(targetFWHM2-nativeFWHM2)/2.35482; covariance A*diag(native_variance)*A^T follows correctly. Region margins cover the kernels for the declared FWHM scenarios. Flat-density normalization and finite-window tests provide appropriate numerical checks; they do not measure the native LSF or hidden covariance introduced by the original extraction.
The saved real-noise Monte Carlo agrees with first-order propagated EW sigma: .125974 versus.126070A and.080952 versus.079450A. A representative variance decomposition includes a negative line/continuum cross term, as expected for a shared linear convolution; it is not discarded. Repeated exposures are averaged within night, and the primary contrast averages two2008nights against one2009Nov12night. The three2009Nov12exposures are not three independent event nights.
Actual retained primary contrast is.480466A with conditional sigma.084532A and formal ratio5.684. That is not the attachment's invented1.34−1.20=.14A dataset, and it must not be reported as a calibrated5.7sigma intrinsic stellar variation. Unknown original resampling covariance, assumed LSFs, continuum windows, extraction/sky systematics and night-shared errors remain. Broadband sky-like offsets and continuum-only bias are correctly separate perturbations. Scaling an exported sky band is a sensitivity scenario, not proof that such a residual exists. No resolved Ti/Fe LDR, atmosphere temperature or stellar RV is inferred. The independent-scenario envelopes are deliberately not statistical confidence intervals.

TESS time basis, gaps and injections
All eight inventoried FITS products report BJDREFI2457000; periodic_design adds the same2457000 reference to BTJD before calling the pre-existing orbit basis, whose signal subtracts it. This correctly preserves phase units. Constant/linear sector nuisance is jointly projected from both data and template (Frisch–Waugh–Lovell algebra); it does not detrend only the observations. Period35.9204566d and its17.9602283d harmonic remain fixed. The retained-energy/condition diagnostics correctly warn about short-sector identifiability; they do not imply a recovered orbital signal or its exclusion.
QUALITY0 plus finite positive flux/error screening occurs before analysis with no amplitude clipping. Actual native timestamps are sorted and kept,20-minute bins are occupied-bin means, and large missing intervals are not filled. Event scores reject windows with large internal gaps. Signed equivalent duration only integrates adjacent observed bins below a gap threshold; it does not span large holes. Baseline plotting also keeps gaps open.
Event injection applies shapes at quality-retained native timestamps before20-minute binning and then repeats the same running-median processing. The restricted baseline-update helper is equivalent to recomputing all affected time windows; a dedicated regression verifies it. Local event windows search all declared score durations around the true injection. Threshold crossings, pre-existing crossings, new crossings, visibility and paired projection response are separately retained. The analytic flare-shape area includes the triangular rise and truncated exponential decay. Native-cadence visibility is a Riemann-sum diagnostic, so tiny values above unity from sampling are not probabilities.
The observed-residual block bootstrap is explicitly a descriptive maximum-statistic screen, not a signal-free stationary null or formal FAP. Blocks are indexed in observed sample order, so gaps/nonstationarity/possible signals can affect the threshold. The current reporting preserves these limits. White-scaled scores must not be converted to Gaussian sigmas. Eight extracted light curves and16SAP/corrected series are alternative reductions of the same photons, not16 independent experiments.
The injection grid probes the saved, upstream-processed light curves after their quality selection. It cannot calibrate attenuation already imposed by QLP/SPOC detrending, lost quality-flag intervals, aperture contamination or finite-exposure integration. Twenty-four times per product and a few event morphologies are bounded response samples, not a universal completeness curve. The report correctly makes no bolometric flare energies, transit-radius limits,100ppm precision claim,0.002mag limit or calibrated3sigma nondetection. Separate sector normalization precludes a multi-year DC brightness inference. Candidate flux excursions remain unvetted, with ancillary/reduction comparisons as diagnostics rather than astrophysical labels.
