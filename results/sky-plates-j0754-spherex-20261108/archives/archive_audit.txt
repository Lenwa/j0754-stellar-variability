from the target. NUV AB magnitude = 18.6138439 +/- 0.0528619, flux = 130.155258

star. That earlier catalogue-subset null therefore does not establish absence

AB zero point. Raw responses: galex_mast.json and galex_observations.txt.

NEW DATA: SWIFT X-RAY COUNTERPART CANDIDATE

2SXPS 161839 = 2SXPS J075445.6+164139 is 3.882 arcsec from Gaia, within the X-ray
90% error radius of 5.6 arcsec. The target's proper-motion displacement between
2009 and the Gaia reference epoch is only about 0.02 arcsec. Detection flag 0
and field flag 0 both mean Good. Catalogue exposure = 4183 s, total counts = 18,
mean 0.3–10 keV count rate = 0.00506 +/- 0.00134 count/s. The native stacked
source detection lists S/N = 2.9 and source likelihood = 40. These are different
archive statistics, not a new independently calibrated significance estimate.

Catalogue date coverage is 2009-12-02 through 2010-10-09. The actual downloaded
light curve contains one per-observation retrospective rate at MJD 55167.695518,
2009-12-02: 0.0050573 (+0.0014014, -0.0011969) count/s. Two snapshot rates are
0.00316794 (+0.00171806, -0.00130338) and 0.006963 (+0.00234485, -0.00193203).
They share the same photons as the per-observation result and stacked detection.
No separate 2010 rate was recovered. Catalogue NObs = 2 is not a count of two
independent recovered epochs. Dataset 2 exports are upper-limit alternatives for
the same bins, not extra observations. The parsed rates retain this distinction.

Power-law observed flux = 1.545e-13 +/- 4.094e-14 erg/cm2/s; unabsorbed flux =
2.056e-13. WhichPow = 1 means a hardness-ratio-derived conversion, not a fitted
spectrum. APEC observed flux = 1.118e-13 +/- 2.963e-14; unabsorbed = 1.265e-13.
WhichAPEC = 0 means a fixed kT = 1 keV spectrum with Galactic NH = 4.34e20 cm^-2.
HasSpec = 0. Flux errors propagate count-rate errors and omit spectral-model
uncertainty. HR1 = -0.242 (+0.2133, -0.2668), HR2 = -0.527 (+0.1178, -0.4725).
No fitted temperature, line diagnostic or precise X-ray spectrum was recovered.

The native 2SXPS cross-match names the exact 2MASS and AllWISE star. Gaia queries
without a magnitude cut, and AllWISE queries, each return only the target within
20 arcsec of the X-ray centroid. AllWISE cc_flags = 0000. This strengthens the
positional association but cannot exclude uncatalogued or unresolved sources,
background objects, or an accidental association. X-ray emission is compatible
with stellar activity among other possibilities; it does not identify the
cause of fading.

NEW DATA: FLAGGED SWIFT UVW1 PHOTOMETRY

00031554001, starting 2009-12-02. UVW1 Vega magnitude = 15.2100 +/- 0.0058,

NEW NEAR-INFRARED PIXELS: UHS SATURATION LIMITATIONS

The official WSA HTTPS hostname has a TLS certificate mismatch; its documented
HTTP site and public query service on port 8080 work without login. Public UHS
DR3, released 2025-09-17, returned one merged source and two target detections.
An all-frame image query returned 15 covering rows: a stack and four normal
frames each at J (2013-01-08), K (2019-01-05), and H (2023-01-09). These are
three physical band/epoch groups, not 15 independent measurements. The merged
astrometric epoch 2016.015 is not an actual simultaneous JHK date.

J aperture-3 magnitude = 10.408772 +/- 0.000551 has ppErrBits = 65552: bit 16
(close to saturation) plus bit 4 (deblended). K = 9.913033 +/- 0.000599 has
ppErrBits = 65536 (bit 16). Formal errors do not make saturated fluxes accurate.
H stack 13146294 has deprecated = 69 and no curated target measurement. Code 69
was not decoded here. A guessed generic Detection table was invalid; that error
is not a target nondetection. Native source, detection and Multiframe CSVs are
saved unchanged with separate parsed exports that remove only comment lines.

Three native gzip FITS cutouts, each 151 by 151 pixels, were recovered. Central
21-pixel-region maxima are 53332 (J), 53276.75 (H), and 55780 (K) ADU; 16, 17,
and 19 pixels respectively exceed 40000 ADU, the documented nightly-stack
close-to-saturation criterion. No PSF-wing reconstruction was attempted. The
pixels are a possible later technical project, not validated new photometry.
Cross-year J-K is not a simultaneous colour, and these data do not measure the
colour of the 2018–22 fade. Files uhs_[JHK]_native_cutout.fits preserve original
gzip bytes despite the .fits suffix; astropy reads them correctly.

NEW OPTICAL ROWS: PTF MOSTLY SATURATED

A 5 arcsec IRSA query returns 84 actual epoch rows: 10 g and 74 R, from two
source IDs at the target, 2009-12-03 through 2015-01-25. All 84 have goodflag = 1
and qaflags = 0. Those summary fields alone are insufficient: 82 rows carry
SExtractor saturation flag value 4 and image-mask bit 8. Some uncalibrated
magnitudes are grossly negative and remain preserved. Photcalflag is 0 for 29
rows; nbestobs is 0 for both source objects.

Two rows have no SExtractor saturation, only informational image-mask bit 1
(pre-flattening SExtractor detection), and photcalflag = 1. Retain them as sparse
candidates: g = 12.583 +/- 0.180 on 2014-11-18 and R = 11.761 +/- 0.087 on
2015-01-23. Different dates and filters prevent a useful light curve or colour.
ptf_all_rows_quality_audit.csv preserves every native column plus decoded bits;
ptf_two_unsaturated_candidates.csv isolates these two explicitly marked rows.
No cross-survey shift, interpolation or comparison-star correction was applied.
