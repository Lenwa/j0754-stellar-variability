<p>Get TESS Input Catalog entries by filtering based on column (as in Advanced Search). Note: It is recommended to use Mast.Catalogs.Filtered.Tic.Rows to download results.</p>
<h3 class="doxsection"><a class="anchor" id="autotoc_md0"></a>
Parameters</h3>
<ul>
<li><b>columns:</b> string (required) Specifies the columns to be returned. "COUNT_BIG(*)" will return the number of observations returned from the query, but does not return the results themselves. "c.*" will return all the columns, as in a CAOM cone search. <br  />
</li>
<li><b>filters:</b> list of json objects (required) List of the filters to be applied.<br  />
A Filter has the form:<br  />
<ul>
<li><b>paramName:</b> Required string giving the column being filtered.<br  />
</li>
<li><b>values:</b> Required list of acceptable values for the column. If the column has discrete values the list will be of the form [val1,val2], and the values will be matched exactly. If the column is continuous the list will be of the form [{"min":minval,"max":maxval}]. If using the freeText parameter, values may be an empty list ([]).<br  />
</li>
<li><b>separator:</b> Optional string giving the separator for a multi-valued column (see <a class="el" href="_t_i_cfields.html" title="TIC Field Descriptions">TIC Field documentation</a> for which columns are multi-valued).<br  />
</li>
<li><b>freeText:</b> Optional string, free text to search for in the column. Allows wildcarding, but must be explicit. Wildcard character is "%". E.g. "ex%planet%".<br  />
</li>
</ul>
</li>
</ul>

<h1 class="doxsection"><a class="anchor" id="MastScienceInstrumentKeywordsNircam"></a>
Mast.Jwst.Filtered.Nircam</h1>
<p>Get JWST Science Instrument Keyword entries for NIRCAM by filtering based on column (as in Advanced Search).</p>
<h3 class="doxsection"><a class="anchor" id="autotoc_md65"></a>
Parameters</h3>
<ul>
<li><b>columns:</b> string (required) Specifies the columns to be returned. "COUNT_BIG(*)" will return the number of observations returned from the query, but does not return the results themselves. "c.*" will return all the columns, as in a CAOM cone search. <br  />
</li>
<li><b>filters:</b> list of json objects (required) List of the filters to be applied.<br  />
A Filter has the form:<br  />
<ul>
<li><b>paramName:</b> Required string giving the column being filtered.<br  />
</li>
<li><b>values:</b> Required list of acceptable values for the column. If the column has discrete values the list will be of the form [val1,val2], and the values will be matched exactly. If the column is continuous the list will be of the form [{"min":minval,"max":maxval}]. If using the freeText parameter, values may be an empty list ([]).<br  />
</li>
<li><b>separator:</b> Optional string giving the separator for a multi-valued column (see <a class="el" href="_jwst_inst_keywd.html" title="Field Descriptions for JWST Instrument Keywords">JWST Instrument Field documentation</a> for which columns are multi-valued).<br  />
</li>
<li><b>freeText:</b> Optional string, free text to search for in the column. Allows wildcarding, but must be explicit. Wildcard character is "%". E.g. "ex%planet%".<br  />
</li>
</ul>
</li>
</ul>
