9 November 2026. Existing data only. Prior annual plots and approximate event epochs have been inspected, so this is a retrospective descriptive test, not a blind discovery or a period significance calculation.

1. Preserve DASCH blue-sensitive plate series, ASAS V, ASAS-SN camera/filter and infrared systems separately. Summarize annual medians, counts, median observed date and gaps. Do not infer brightness during gaps or identify survey boundaries with event boundaries.
2. Quantify the known 1930s fading/recovery. Inspect smaller 1940s and 1980s features using fixed windows selected from the already available annual plot: 1941-1944 / 1945-1948 / 1949-1956 and 1969-1975 / 1982-1986 / 1987-1989. Calculate common-series contrasts and run the identical windows on comparison-star placebo curves matched to target plate keys. These controls diagnose common behavior; no calibrated false-alarm probability.
3. Test one explicit suggested recurrence: shift the historical 1932-1943 recovery by 44.5 years, half the approximate1933-to2022 separation. At actual lateDASCH dates, compare predicted early-faint/later-bright contrast, retaining series intercepts; fit amplitude with/without linear drift. An equal-depth repeated event would require positive comparable contrast/amplitude. Failure rejects this waveform/timing, not every cycle. The halfinterval is post-hoc; no optimized period or universalperiodlimit.

Plot all historicalannualpoints with sparseyears distinguished, separate modernpanel, and coverage counts. Explain selected-episode spacing is not a fittedperiod.
